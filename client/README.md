# Where's Waldo client
This is the frontend to my Where's Waldo game.

Built with React + Vite.

## How to run
1. Clone this repo and cd into client directory
```bash
git clone https://github.com/gabrielpdmello/wheres-waldo.git
cd wheres-waldo/client
```
2. Install dependencies
```bash
npm install
```
3. Copy the example environment file
```bash
cp .env.example .env
```
4. Update the environment variables
5. Start the application
```bash
npm run dev
```
